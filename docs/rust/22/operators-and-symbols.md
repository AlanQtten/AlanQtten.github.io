# 附录B：运算符和符号

本附录包含了Rust语法的合集，包括运算符和其他或独立或出现在某些上下文、泛型、trait边界、宏、属性、注释、元组和括号里的符号。

## 运算符

下面的表格包括了Rust里的运算符，运算法如何出现在上下文里，一个短的解释，以及那个运算符是不是可以重载的。如果一个运算符可以被重载，那么表中会列出其关联的trait。

| 运算法 | 示例                                             | 解释           | 可重载？       |
| ------ | ------------------------------------------------ | -------------- | -------------- |
| `!`    | `ident!(...)`, `ident!{...}`, `ident![...]`      | 宏展开         |                |
| `!`    | `!expr`                                          | 按位或逻辑补码 | `Not`          |
| `!=`   | `expr != expr`                                   | 不等性对比     | `PartialEq`    |
| `%`    | `expr % expr`                                    | 算数取余       | `Rem`          |
| `%=`   | `var %= expr`                                    | 算数取余并赋值 | `RemAssign`    |
| `&`    | `&expr`, `&mut expr`                             | 借用           |                |
| `&`    | `&type`, `&mut type`, `&'a type`, `&'a mut type` | 借用指针类型   |                |
| `&`    | `expr & expr`                                    | 按位与         | `BitAnd`       |
| `&=`   | `var &= expr`                                    | 按位与并赋值   | `BitAndAssign` |
| `&&`   | `expr && expr`                                   | 短路逻辑与     |                |
| `*`    | `expr * expr`                                    | 算数相乘        | `Mut`          |
| `*=`   | `var *= expr`                                    | 算法相乘并赋值  | `MutAssign`    |
| `*`    | `*expr`                                          | 解引用         | `Deref`        |
| `*`    | `*const type`, `*mut type`                       | 原始指针       |                |
| `+`    | `trait + trait`, `'a + trait`                    | 组合类型约束   |                |
| `+` | `expr + expr` | 算法相加 | `Add` |
| `+=` | `var += expr` | 算法相加并赋值 | `AddAssign` |
| `,` | `expr` | 参数和元素分隔符 |  |
| `-` | `- expr` | 算数否 | `Neg` |
| `-` | `expr - expr` | 算数相减 | `Sub` |
| `-=` | `var -= expr` | 算数相减并赋值 | `SubAssign` |
| `->` | `fn(...) -> type`, `\|...\| -> type` | 函数和闭包返回类型 |  |
| `.` | `expr.ident` | 属性访问 | |
| `.` | `expr.ident(expr, ...)` | 方法调用 | |
| `.` | `expr.0`, `expr.1`等等 | 元组下标访问 | |
| `..` | `..`, `expr..`, `..expr`, `expr..expr` | 右侧开区间字面量 | `PartialOrd` |
| `..=` | `..=expr`, `expr..=expr` | 右侧闭区间字面量 | `PartialOrd` |
| `..` | `..expr` | 结构体字面量更新语法 |  |
| `..` | `variant(x, ..)`, `struct_type { x, .. }` | “包含剩余”模式绑定 |  |
| `...` | `expr...expr` | （已废弃，请使用`..=`）在模式内表示闭区间 |  |
| `/` | `expr / expr` | 算数除 | `Div` |
| `/=` | `var /= expr` | 算法除并赋值 | `DivAssign` |
| `:` | `pat: type`, `ident: type` | 约束 |  |
| `:` | `ident: expr` | 结构体字段初始化 |  |
| `:` | `'a: loop {...}` | 循环标签 |  |
| `;` | `expr;` | 声明和元素终止符 |  |
| `;` | `[...; len]` | 固定尺寸数组语法的一部分 |  |
| `<<` | `expr << expr` | 左移 | `Shl` |
| `<<=` | `var <<= expr` | 左移并赋值 | `ShlAssign` |
| `<` | `expr < expr` | 小于比较 | `PartialOrd` |
| `<=` | `expr <= expr` | 小于等于比较 | `PartialOrd` |
| `=` | `var = expr`, `ident = type` | 赋值/等价 |  |
| `==` | `expr == expr` | 相等性比较 | `PartialEq` |
| `=>` | `pat => expr` | match分支语法的一部分 |  |
| `>` | `expr > expr` | 大于比较 | `PartialOrd` |
| `>=` | `expr >= expr` | 大于等于比较 | `PartialOrd` |
| `>>` | `expr >> expr` | 右移 | `Shr` |
| `>>=` | `var >>= expr` | 右移并赋值 | `ShrAssign` |
| `@` | `ident @ pat` | 模式绑定 |  |
| `^` | `expr ^ expr` | 按位异或 | `BitXor` |
| `^=` | `var ^= expr` | 按位异或并赋值 | `BitXorAssign` |
| `\|` | `pat \| pat` | 模式替代 |  |
| `\|` | `expr \| expr` | 按位或 | `BitOr` |
| `\|=` | `var \|= expr` | 按位或并赋值 | `BitOrAssign` |
| `\|\|` | `expr \|\| expr` | 短路逻辑或 |  |
| `?` | `expr?` | 错误传播 |  |

## 非运算符符号

下面的列表列举了所有的非运算符功能的符号；也就是说，它们不会表现得像函数或者方法的调用一样。

下面的表格展示了一些可以独立出现，也可以在很多地方有效的符号：

| 符号                                        | 解释                                             |
| ------------------------------------------- | ------------------------------------------------ |
| `'ident`                                    | 生命周期和循环标签命名                           |
| `...u8`, `...i32`, `...f64`, `...usize`等等 | 特定类型的数字字面量                             |
| `"..."`                                     | 字符串字面量                                     |
| `r"..."`, `r#"..."#`, `r##"..."##`等等      | 原始字符串字面量，不处理转义字符                 |
| `b"..."`                                    | 字节码字符串字面量；构造字节数组而不是字符串     |
| `br"..."`, `br#"..."#`, `br##"..."##`等等   | 原始字节码字符串字面量，结合了原始和字节码字符串 |
| `'...'`                                     | 字符字面量                                       |
| `b'...'`                                    | ASCII字节字面量                                  |
| `\|...\| expr`                              | 闭包                                             |
| `!`                                         | 底部类型为空，为了不同的功能                     |
| `-`                                         | “忽略“模式绑定；也用于提高整数字面量的可读性     |

下面的表格展示了一些在使用模块时使用的符号：

| 符号                                    | 解释                                                         |
| --------------------------------------- | ------------------------------------------------------------ |
| `ident::ident`                          | 命名空间路径                                                 |
| `::path`                                | 基于预引入外部模块的相对路径，其他的crate均在根下（换句话说，一个包含crate名的绝对路径） |
| `self::path`                            | 基于当前模块的相对路径（换句话说，就是相对路径）             |
| `super::path`                           | 基于父模块的相对路径                                         |
| `type::ident`, `<type as trait>::ident` | 关联约束，函数和类型                                         |
| `<type>::...`                           | 不能直接使用名字的和类型关联的元素（比如`<&T>::...`, `<[T]>::...`等等） |
| `trait::method(...)`                    | 通过trait的名字来调用其关联函数，消除歧义                    |
| `type::method(...)`                     | 通过类型的名字来调用其关联函数，消除歧义                     |
| `<type as trait>::method(...)`          | 通过trait和类型的名字来调用其关联函数，消除歧义              |

下面的表格展示了一些在使用泛型类型时使用的符号：

| 符号                           | 解释                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| `path<...>`                    | 指定泛型类型参数的类型，比如`Vec<u8>`                        |
| `path::<...>`, `method::<...>` | 在一个表达式里为函数或方法指定其泛型类型参数的类型，社区里也把它叫做“涡轮鱼”（比如，`"42".parse::<i32>()`） |
| `fn ident<...> ...`            | 定义泛型函数                                                 |
| `struct ident<...> ...`        | 定义泛型结构体                                               |
| `enum ident<...> ...`          | 定义泛型枚举                                                 |
| `impl<...> ...`                | 定义泛型实现                                                 |
| `for<...> type`                | 更高维的生命周期约束                                         |
| `type<ident=type>`             | 一个泛型类型拥有一个或多个指定赋值的关联类型（比如，`Iterator<Item=T>`） |

下面的表格展示了使用trait边界约束泛型类型参数的过程中使用的符号：

| 符号                          | 解释                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| `T: U`                        | 泛型类型参数`T`被约束为需要实现`U`                           |
| `T: 'a`                       | 泛型类型参数`T`的生命周期比如大于等于`'a`（也就表示这个类型内部也不能有任何生命周期短于`'a`的引用） |
| `T: 'static`                  | 泛型类型`T`不能包含任何非`'static`的借用引用                 |
| `'b: 'a`                      | 生命周期`'b`必须大于等于`'a`                                 |
| `T: ?Sized`                   | 允许泛型类型参数是一个动态尺寸的类型                         |
| `'a + trait`, `trait + trait` | 联合类型约束                                                 |

下面的表格展示了调用和定义宏以及声明元素属性时的符号：

| 符号                                        | 解释     |
| ------------------------------------------- | -------- |
| `#[meta]`                                   | 外部属性 |
| `#![meta]`                                  | 内部属性 |
| `$ident`                                    | 宏替换   |
| `$ident:kind`                               | 宏捕获   |
| `$(...)...`                                 | 宏重复   |
| `ident!(...)`, `ident!{...}`, `ident![...]` | 宏调用   |

下面的表格展示了创建注释中使用的符号：

| 符号       | 解释         |
| ---------- | ------------ |
| `//`       | 行注释       |
| `//!`      | 行内文档注释 |
| `///`      | 行外文档注释 |
| `/*...*/`  | 块注释       |
| `/*!...*/` | 块内文档注释 |
| `/**...*/` | 块外文档注释 |

下面的表格展示了小括号的使用：

| 符号              | 解释                                                   |
| ----------------- | ------------------------------------------------------ |
| `()`              | 空的元组（也就是元类型），即是类型也是字面量           |
| `(expr)`          | 括号表达式                                             |
| `(expr,)`         | 单个元素的元组                                         |
| `(type,)`         | 单个元素的元组类型                                     |
| `(expr, ...)`     | 元组表达式                                             |
| `(type, ...)`     | 元组类型                                               |
| `expr(expr, ...)` | 函数调用表达式；也被用于初始化元组结构体和元组枚举变体 |

下面的表格展示了大括号的使用场景：

| 场景         | 解释         |
| ------------ | ------------ |
| `{...}`      | 块表达式     |
| `Type {...}` | 结构体字面量 |

下面的表格展示了中括号的使用场景：

| 场景                                               | 解释                                                         |
| -------------------------------------------------- | ------------------------------------------------------------ |
| `[...]`                                            | 数组字面量                                                   |
| `[expr; len]`                                      | 数组字面量，包含了`len`个`expr`                              |
| `[type; len]`                                      | 数组类型，包含了`len`个`expr`                                |
| `expr[expr]`                                       | 集合下标，可重载（`Index`, `IndexMut`）                      |
| `expr[..]`, `expr[a..]`, `expr[b..]`, `expr[a..b]` | 集合下标的切片语法糖，使用`Range`、`RangeFrom`、`RangeTo`和`RangeFull`作为“下标” |
